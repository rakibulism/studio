# **App Name**: Vibe Forge

## Core Features:

- Tools Landing Page: Displays a list of creative tools as clickable cards for easy access.
- Color Palette Generator: AI-powered color palette generation tool using a text prompt, based on adjectives to generate a harmonized list of colors.
- Gradient Creator: Tool for creating custom CSS gradients. Lets users combine colors to generate gradient code.
- Typography Helper: A typography helper tool providing font suggestions and pairings based on design context and mood, with a choice of only Google Fonts to make implementation simple.
- SVG Shape Builder: An SVG shape builder that allows users to design and export custom SVG shapes, ready to copy and paste into HTML or other software.

## Style Guidelines:

- Dark background with a deep, desaturated indigo (#1A1A33) to set a modern and sophisticated tone.
- Primary color: Electric purple (#BE52F2) to add energy and highlight important interactive elements.
- Accent color: Cyan (#43D8C9) for secondary interactive elements, providing a cool contrast against the purple.
- Body and headline font: 'Space Grotesk' (sans-serif) for a modern, techy feel.
- Use minimalist icons with neon outlines, matching the primary and accent colors.
- Cards with a sleek, dark design to display the tool menu on the home page
- Subtle transitions and animations when tools load and change to reinforce an engaging experience
